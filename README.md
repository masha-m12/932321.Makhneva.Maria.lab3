# 932321.Makhneva.Maria.lab3

## Лабораторная работа №3. Вёрстка макета с помощью Flexbox и Grid.

### Описание работы

Дополнена HTML-страница «О себе» из предыдущих лабораторных работ с помощью внешнего CSS-файла (style.css). Реализованы одномерные раскладки на Flexbox (навигационное меню и карточки «Хобби») и двумерная Grid-сетка («Любимые места»). Добавлены медиа-запросы для планшетов и мобильных устройств.  

### Реализация

Навигационное меню: горизонтальное меню с использованием Flexbox.  
Карточки хобби: три карточки с изображениями, названиями и краткими описаниями.  
Сетка любимых мест: шесть карточек с фотографиями, названиями городов и описаниями.  
Адаптивная вёрстка: количество колонок сетки изменяется в зависимости от ширины экрана. Для адаптации страницы используются медиазапросы:  
- десктоп (> 992px) — 3 колонки;  
- планшет (600–992px) — 2 колонки;  
- мобильный (< 600px) — 1 колонка, меню вертикальное.  
Оформление фотографий любимых мест: подписи к фотографиям размещены поверх изображений с использованием тёмного градиента и текстовой тени.
